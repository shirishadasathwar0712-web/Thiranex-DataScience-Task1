# Thiranex Data Science Internship – Task 1

## Project Title

Sales Data Cleaning, Processing, and Visualization

## Project Overview

This project focuses on cleaning and analyzing a sales dataset using Python. It demonstrates data preprocessing, outlier handling, sales calculations, and data visualization.

**Dataset note:** The dataset used in this project is a synthetic practice dataset created for learning and demonstration purposes.

## Tools and Libraries

* Python
* Pandas
* Matplotlib
* Seaborn

## Tasks Completed

1. Loaded and explored the raw dataset.
2. Identified and handled missing values.
3. Detected and removed duplicate rows.
4. Identified quantity outliers using the IQR method.
5. Handled the extreme quantity outlier.
6. Created a Total_Sales column.
7. Converted the Date column to datetime format.
8. Created visualizations for category sales, city sales, and sales trends.
9. Saved the cleaned dataset.
10. Calculated key sales insights.

## Key Results

* Original dataset: 21 rows and 7 columns.
* Cleaned dataset: 20 rows and 8 columns.
* Total sales: 808100.
* Best category by sales: Electronics.
* Best city by sales: Chennai.
* Best product by sales: Laptop.

## Visualizations

Three charts were created:

* Total Sales by Category
* Total Sales by City
* Sales Trend by Date

The charts are available in the `visualizations` folder.

## Project Files

* `raw_sales_data.csv` – Original practice dataset.
* `cleaned_sales_data.csv` – Cleaned dataset with the Total_Sales column.

## Learning Outcomes

This project provided practical experience with data cleaning, preprocessing, outlier detection, Pandas, and data visualization using Matplotlib and Seaborn.
